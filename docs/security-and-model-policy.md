# 安全与模型外发策略

> 历史文档：本文针对原“内网文档解析与 RAG”阶段撰写。项目当前定位及阶段顺序见仓库根目录 [README](../README.md)。默认拒绝外发、最小权限和审计原则继续适用；知识库、核物理资料、BFF 等具体范围不代表当前个人行为基线 Agent 的实施计划。真实个人观测数据还需要单独定义授权、撤回、用途限制与衍生数据处理规则。

## 目的与适用范围

本文定义 `rag_parse` 第一阶段（文档解析、检索、带引用问答）必须遵循的数据访问、模型调用和审计边界。它适用于 API、异步 Worker、向量库、对象存储、日志和后续 Agent 工具。

默认原则：**先鉴权、再检索、后生成；默认拒绝外发；最小化传输与留存。**

## 数据分级

| 等级 | 含义 | 可存储位置 | 默认模型策略 |
| --- | --- | --- | --- |
| `public` | 已明确可公开发布的资料 | 经批准的内网或云端存储 | 可调用经批准的云端或内网模型 |
| `internal` | 研究所内部使用、但未标记为受限的资料 | 内网受控存储 | 默认仅内网模型；云端调用须由显式策略批准 |
| `restricted` | 涉密、敏感研究、受限合作或含个人/受控信息的资料 | 内网受控存储；加密、最小权限 | 不得向任何外部模型发送；只允许批准的内网模型，或仅检索不生成 |

数据等级必须在知识库创建时指定。文档可提高但不可降低知识库等级；片段继承文档等级，且不得低于知识库等级。等级变更、外发例外和策略调整均须记录审计事件。

## 模型信任范围与外发判定

模型提供方须登记为下列信任范围之一：

- `internal`: 研究所批准的内网部署模型；数据不离开内网受控边界。
- `external_approved`: 经安全审批的阿里云、DeepSeek 等外部服务。
- `external_unapproved`: 未经审批的服务，系统不得配置或调用。

在每次 `chat`、`embedding`、`rerank` 调用前，模型网关必须根据请求涉及的最高数据等级、模型信任范围和 `model_policy` 做出决定。策略按操作分别配置，不能以“聊天模型可用”推断 Embedding 或重排服务也可用。

默认矩阵如下；`allow_exception` 只能由安全管理员创建，并应具有到期时间、审批记录和适用范围。

| 数据等级 | 内网模型 | 已批准外部模型 | 未批准外部模型 |
| --- | --- | --- |
| `public` | 允许 | 允许 | 拒绝 |
| `internal` | 允许 | 拒绝，除非有效例外明确允许 | 拒绝 |
| `restricted` | 允许（须模型本身获该等级批准） | 拒绝 | 拒绝 |

若一次请求包含多个片段，以其中最高等级判定；无法确定等级、策略、模型身份或请求来源时必须拒绝。拒绝结果不得包含原文、片段或提示词内容。

## 强制执行点

1. **上传与解析**：API 在写入对象存储前校验知识库写权限、文件大小、类型、等级和恶意文件扫描结果。解析 Worker 使用隔离进程和无网络权限的解析器；原始文件不进入日志或任务消息体。
2. **索引**：每个向量与片段元数据必须包含 `organization_id`、`knowledge_base_id`、`document_id`、`classification`、索引版本和删除状态。向量库过滤条件由服务端生成，客户端不得传入可绕过的过滤器。
3. **检索**：先验证组织、知识库成员资格和文档/片段权限，再向检索引擎发起带强制过滤条件的查询。仅用“检索后过滤”不满足要求。
4. **生成**：只将鉴权后的、策略允许外发的最少上下文发送到模型网关。网关负责最终策略校验；调用方不得绕过网关直接访问供应商 SDK。
5. **下载与引用**：原文下载、页面预览和引用片段读取均重复执行同一权限检查；引用 ID 不能成为绕过权限的凭证。
6. **Agent（第二期）**：Agent 只能通过授权工具访问数据；工具调用分别执行权限和外发策略检查。禁止向 Agent 提供文件系统、Shell、任意 HTTP 或原始数据库连接。
7. **BFF**：BFF 仅可调用 Core API 并返回面向页面的最小 DTO；不得直连数据库、对象存储、向量库或模型供应商，也不得替代 Core 的权限、检索过滤和外发策略判定。

## 身份与授权

- 所有业务资源归属一个 `organization_id`；所有查询都以已认证主体的组织作为不可覆盖的边界。
- 第一阶段角色为：`admin`、`editor`、`viewer`。知识库成员关系决定读写权限，文档和片段可进一步收紧，不能扩大知识库授权。
- 服务间身份使用短期、轮换的凭据；前端永不接触模型 API Key、对象存储管理凭据或数据库凭据。
- 未认证、跨组织、资源不存在和无权限请求统一返回不泄露资源存在性的响应。

## 最小化、日志与审计

- 常规日志不得记录文件正文、完整提示词、完整模型回复、授权令牌、API Key 或对象存储签名 URL。
- 模型调用仅记录：请求 ID、组织 ID、数据最高等级、策略版本、模型标识/信任范围、操作类型、时间、耗时、token 用量、允许/拒绝结果和错误类别。
- 审计日志记录登录、成员与策略变更、上传/删除、下载、检索、引用访问、模型调用决定及 Agent 工具调用。审计日志应追加写入并受限读取。
- 对外部模型，默认不保存请求/响应正文；若为排障临时启用，必须脱敏、获得审批、设置自动过期，并记录启用原因。

## 密钥、网络与存储

- 供应商 Key 仅来自运行时密钥服务或部署环境变量；不得写入仓库、数据库业务表、任务队列、客户端或日志。
- API、Worker、PostgreSQL、Redis、Qdrant 和对象存储部署在私有网络；仅网关可按显式出站规则访问批准的外部模型域名。
- 传输使用 TLS；原始文件、解析产物、备份和敏感索引使用经批准的静态加密。备份遵循同等访问控制与保留策略。
- 删除文档必须同时建立索引删除/失效任务；在完成前，检索层按删除状态强制排除对应片段。

## 实施前提与待确认项

以下事项会影响生产部署参数，但不改变上述默认拒绝策略：身份源（LDAP/OIDC/本地账号）、外部 API 的网络可达性与审批状态、数据保留期限、密钥服务、各内网模型的实际能力和获批数据等级。

在这些项明确前，开发环境只允许使用无敏感内容的测试资料和 mock 模型；不得填入真实供应商凭据或受限资料。

## 验收清单

- 使用 `restricted` 文档请求外部 chat、embedding、rerank 均被网关拒绝，且日志不含原文。
- 无知识库读取权限的用户不能通过搜索、引用 ID、文档下载或向量过滤参数获得任何片段。
- `internal` 内容只有带有效、未过期例外时才可交给对应的批准外部模型。
- 每次模型允许/拒绝决定均可关联请求 ID、策略版本和模型配置，但不保存敏感正文。
- 已删除文档的片段不能被检索或引用；删除操作可审计。
